# TeamCode (by Live Code)
> **Building real products, gaining real reputation.**

**Current Version:** `v0.1.0-alpha`

## The Vision
TeamCode is not just another coding sandbox or tutorial platform. It is a **Project Incubator**. 
We connect driven junior developers into well-balanced teams to build, ship, and maintain real-world Open Source products. 

Through our **Progressive Profiling** and **Proof Engine**, developers earn a verified **Reputation Score** based on actual GitHub contributions, teamwork, and code quality. Stand out in the industry not by what your resume says, but by the code you ship.

## 🏗️ The Open Core Architecture
We believe in transparency with our community. This repository contains the **Open Source Core** of TeamCode:
- **Models (The Contract):** How we structure our developers and teams.
- **API Engine:** The routes and controllers managing the platform.

*(Note: The internal calculation algorithms for the Reputation Score and Webhook anti-spam validations are kept in a closed-core environment to maintain the integrity of the Live Code Certification).*
